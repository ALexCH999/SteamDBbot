# SteamDB Bot 🤖

Telegram-бот для поиска игр на **Steam** с подробной информацией:
цена, разработчик, платформы, Metacritic, текущий онлайн и пиковые значения игроков.

---

## Возможности

- 🔍 Поиск игр по названию
- 🎮 Полная карточка игры: имя, цена, релиз, разработчик, издатель, платформы
- 📈 Текущий онлайн и пики (24 ч / all-time) из SteamCharts
- 📝 Описание и системные требования
- 🇷🇺/🇬🇧 Поддержка русского и английского языков
- 💾 Кэширование в Redis (с in-memory fallback)

---

## Tech Stack

- Python 3.12
- [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot) v20.6
- Redis (опционально)
- uv — менеджер пакетов и виртуального окружения

---

## Быстрый старт

### 1. Установка зависимостей
```bash
uv sync
```

### 2. Настройка окружения
Создай файл `.env` в корне проекта:
```env
BOT_TOKEN=your_telegram_bot_token
REDIS_URL=redis://localhost:6379/0
CACHE_TTL=180
ADMIN_IDS=123456789
```

### 3. Запуск
```bash
uv run python main.py
```

---

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Запуск и выбор языка |
| `/help` | Справка |
| `/lang ru` / `/lang en` | Сменить язык |
| `/stats` | Статистика (только админ) |

Просто напиши название игры, например: `Dota 2`.
